Análise Temporal e Horária

Tendências Temporais

Compreender quando os crimes ocorrem é fundamental para o planejamento do policiamento ostensivo.

Evolução Diária

O gráfico de linha abaixo mostra a variação diária das ocorrências no período analisado.

Code 
temp_df = pd.DataFrame(data['serie_temporal'], columns=['Data', 'Ocorrências'])
fig_temp = px.line(temp_df, x='Data', y='Ocorrências', markers=True)
fig_temp.update_layout(xaxis_title="Data do Fato", yaxis_title="Quantidade")
fig_temp.show()

Mancha Horária

A distribuição das ocorrências ao longo das 24 horas do dia revela os períodos de maior vulnerabilidade.

Code 
hora_df = pd.DataFrame(list(data['dist_hora'].items()), columns=['Hora', 'Total'])
fig_hora = px.bar(hora_df, x='Hora', y='Total', color='Total', color_continuous_scale='Plasma')
fig_hora.update_layout(xaxis_title="Hora (0-23h)", yaxis_title="Total de Ocorrências")
fig_hora.show()
Insight Analítico

Observa-se que a maioria das ocorrências de furto e roubo tendem a se concentrar em janelas específicas, o que permite o redirecionamento de viaturas para os horários de pico identificados.
